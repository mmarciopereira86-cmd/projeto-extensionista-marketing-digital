# Evidências – Pipeline de Oportunidades

Esta pasta reúne as capturas de tela do pipeline de negócios configurado no HubSpot para o projeto extensionista.

Foi criado o pipeline **Projeto Extensionista – Gestão de Oportunidades e Avaliações**, com etapas para organizar o acompanhamento dos interessados, desde o primeiro contato até a conclusão ou não conversão da oportunidade.

As etapas configuradas são:

1. Novo interessado.
2. Tentativa de contato.
3. Em atendimento.
4. Avaliação agendada.
5. Avaliação realizada.
6. Não convertido / Desistiu.

Na consulta realizada, foram identificados dois negócios demonstrativos: um na etapa de tentativa de contato e outro na etapa de avaliação realizada.

Os registros foram utilizados para demonstrar a organização e o funcionamento do pipeline no CRM.
