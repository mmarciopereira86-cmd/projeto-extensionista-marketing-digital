# Evidências – Automação HubSpot

Esta pasta reúne as capturas de tela da configuração do workflow utilizado no projeto extensionista.

A automação foi configurada para identificar contatos que preenchem o formulário do site, atualizar suas propriedades no CRM e criar uma tarefa de acompanhamento para o responsável pelo contato.

As imagens serão utilizadas para demonstrar a configuração e as ações implementadas.
